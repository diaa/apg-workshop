2. INHERIT vs NOINHERIT — What Happens at Login

When a user with INHERIT connects, they automatically get all privileges from their parent group role. When a user with NOINHERIT connects, they start with zero privileges and must explicitly SET ROLE to activate them — similar to sudo on Linux.
